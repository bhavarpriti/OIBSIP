# Random Password Generator

## Project Name
Random Password Generator using Python

## Purpose
The purpose of this project is to generate strong and random passwords using Python.

This project is created as part of the OASIS INFOBYTE Python Programming Internship.

## Features
- Generates random passwords.
- Allows the user to choose the password length.
- Requires a minimum password length of 8 characters.
- Uses uppercase letters, lowercase letters, numbers, and special characters.
- Handles invalid input.

## Technologies Used
- Python 3
- Visual Studio Code
- `string` module
- `secrets` module

## How to Run
1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the command:

   `python password_generator.py`

5. Enter the desired password length (minimum 8).
6. View your generated password.

## Example Output

```text
===== RANDOM PASSWORD GENERATOR =====
Enter password length (minimum 8): 12

Your generated password is: [randomly generated password]
Password generated successfully!
```
