# BMI Calculator

## Project Name
BMI Calculator using Python

## Purpose
The purpose of this project is to calculate Body Mass Index (BMI) using a person's weight and height. It also displays a BMI category based on the calculated result.

This project is created as part of the OASIS INFOBYTE Python Programming internship task.

## Features
- Takes weight as input in kilograms.
- Takes height as input in meters.
- Calculates BMI using the BMI formula.
- Displays BMI up to two decimal places.
- Shows categories: Underweight, Normal weight, Overweight, and Obese.
- Handles invalid text input.
- Checks that weight and height are greater than zero.

## Technologies Used
- Python 3
- Visual Studio Code

## BMI Formula
BMI = Weight (kg) / Height (m)²

## How to Run
1. Install Python 3 on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the VS Code terminal.
4. Run the following command:

   `python bmi_calculator.py`

5. Enter your weight in kilograms when prompted.
6. Enter your height in meters when prompted.
7. View your BMI result and category in the terminal.
