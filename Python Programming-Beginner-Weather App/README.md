
# Weather App

## Project Description
The Weather App is a Python-based application that retrieves weather information for a city entered by the user. It displays the temperature, feels-like temperature, weather conditions, humidity, and wind speed.

## Features
- Search weather information by city name.
- Display current temperature in Celsius.
- Show feels-like temperature.
- Display weather conditions.
- Show humidity percentage.
- Display wind speed in kilometers per hour.
- Handle invalid input and connection errors.

## Technologies Used
- Python
- JSON
- urllib

## Requirements
- Python 3 installed on your computer.
- An active internet connection.
- Access to the wttr.in weather service.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python weather_app.py
```

5. Enter a city name when prompted.
6. View the weather report displayed in the terminal.
